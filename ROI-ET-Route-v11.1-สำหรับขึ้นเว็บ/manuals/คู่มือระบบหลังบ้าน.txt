ROI ET ROUTE — คู่มือติดตั้งระบบหลังบ้าน (Backend v1)
=====================================================================

ระบบหลังบ้านนี้ทำงานบน Netlify Functions + Netlify Blobs (ฐานข้อมูลของ Netlify)
ไม่ต้องเช่าเซิร์ฟเวอร์หรือตั้งฐานข้อมูลเอง อยู่ที่เดียวกับเว็บ roiet-route.netlify.app
ไม่แก้โค้ดเดิมของเว็บ ระบบคำนวณ ข้อมูลจุดส่ง การนำเข้า Excel/CSV ฯลฯ ทำงานเหมือนเดิมทุกอย่าง

---------------------------------------------------------------------
ทำอะไรได้บ้าง
---------------------------------------------------------------------
1) บัญชีผู้ใช้
   - สมัคร / เข้าสู่ระบบ / เปลี่ยนรหัสผ่าน / ออกจากระบบ (ปุ่มมุมขวาบนของเว็บ)
   - สิทธิ์ 3 แบบ: ผู้ดูแลระบบ, ผู้วางแผน, คนขับ
   - คนแรกที่สมัครจะเป็นผู้ดูแลระบบอัตโนมัติ (สมัครทันทีหลังติดตั้ง!)
   - รหัสผ่านเก็บแบบเข้ารหัส (scrypt) ใส่รหัสผิด 8 ครั้งพัก 10 นาที
   - เปลี่ยนรหัส/รีเซ็ตรหัส/ระงับบัญชี แล้วเครื่องที่เข้าระบบค้างไว้ต้องเข้าใหม่

2) เก็บประวัติบนคลาวด์
   - ประวัติการจัดส่ง ร้านประจำ ผลตรวจความแม่นยำ ขึ้นบัญชีอัตโนมัติ
   - ใช้ได้หลายเครื่อง: เปิดจากคอมหรือมือถือก็เห็นข้อมูลเดียวกัน
   - รวมข้อมูลให้เอง: ข้อมูลที่บันทึกในเครื่องก่อนเข้าระบบไม่หาย
     ลบจากเครื่องหนึ่ง อีกเครื่องก็หายตาม (ไม่เด้งกลับ)

3) งานจัดส่ง
   - กด "โหมดคนขับ" ในหน้าวางแผน → งานขึ้นระบบเอง
   - ทุกครั้งที่กด "ส่งสำเร็จ" / "ส่งไม่ได้" สถานะขึ้นระบบทันที
   - มอบหมายงานให้คนขับ (ใส่อีเมลคนขับ) คนขับเปิดเว็บจากมือถือตัวเองแล้ว
     กด "เปิดงานนี้ในโหมดคนขับบนเครื่องนี้" ได้เลย
   - ดูงานทั้งหมดได้ที่เมนูบัญชี > งานจัดส่ง หรือหน้าผู้ดูแลระบบ

4) ระบบแจ้งเตือน
   - มีรายการส่งใหม่ (สร้างงาน/มอบหมายงาน)
   - จัดส่งไม่สำเร็จ (บอกชื่อร้าน จุดที่ และเหตุผล เช่น ร้านปิด ไม่มีคนรับ)
   - เส้นทางมีการเปลี่ยนแปลง (บอกว่าเพิ่ม/ตัดจุดไหน และลำดับใหม่)
   - เพิ่มเติม: จบงานจัดส่ง, ราคาน้ำมันเปลี่ยน (แจ้งผู้ดูแลระบบ)
   - ผู้รับ: เจ้าของงาน + คนขับที่ได้รับมอบหมาย + ผู้ดูแลระบบทุกคน
   - ช่องทาง: กระดิ่งบนเว็บ (ตรวจทุก 20 วินาที), แจ้งเตือนบนเครื่อง (กดอนุญาตในกระดิ่ง)
     และส่งต่อไป Telegram / Discord / LINE ได้ (ตั้งค่าข้อ 6)

5) ราคาน้ำมันอัตโนมัติทุกปั๊ม
   - ดึงราคาเองทุกชั่วโมง (ราคาน้ำมันไทยมักเปลี่ยนตอนตี 5 จึงทันภายใน 1 ชม.)
   - แหล่งข้อมูล: ปตท. (เว็บเซอร์วิสทางการ), บางจาก (มีราคาพรุ่งนี้ด้วย),
     เว็บรวมราคาทุกปั๊ม (เชลล์ พีที คาลเท็กซ์ เอสโซ่ ซัสโก้ ฯลฯ)
   - ตารางเทียบราคาทุกปั๊ม ไฮไลต์ปั๊มที่ถูกที่สุด กดชื่อปั๊มเพื่อใช้ราคานั้นคำนวณ
   - ช่องราคาเดิมในเว็บ (ดีเซล / 95 / E20) อัปเดตให้เอง ตั้งได้ว่าจะใช้ราคาปั๊มไหน
     หรือ "ปั๊มที่ถูกที่สุด" ถ้าพิมพ์ราคาเอง ระบบจะหยุดอัปเดตอัตโนมัติจนกว่าจะเปิดใหม่
   - แหล่งไหนล่ม ใช้แหล่งอื่น/ราคาล่าสุดที่เก็บไว้ เว็บไม่พัง ผู้ดูแลระบบกรอกราคาเองได้
   - หมายเหตุ: เป็นราคากรุงเทพฯ ต่างจังหวัดอาจต่างเล็กน้อยตามค่าขนส่ง

6) หน้าผู้ดูแลระบบ (admin.html)
   - ภาพรวม: จำนวนผู้ใช้ งาน อัตราส่งสำเร็จ ระยะทางรวม สถานะแหล่งราคาน้ำมัน
   - ผู้ใช้: เพิ่มบัญชี (เช่นบัญชีคนขับ) เปลี่ยนสิทธิ์ ระงับ รีเซ็ตรหัสผ่าน
   - งานจัดส่ง: กรองตามสถานะ ดูรายละเอียด มอบหมายคนขับ แก้สถานะจุดส่ง ยกเลิกงาน
   - ราคาน้ำมัน: ตารางทุกปั๊ม ดึงราคาตอนนี้ กรอกราคาเอง
   - การแจ้งเตือน: ข้อความล่าสุด + ปุ่มส่งทดสอบ

  admin.html                       หน้าผู้ดูแลระบบ
  roiet-theme.js / .css            ธีม v5 (รุ่นล่าสุด)

  ถ้าโฟลเดอร์เว็บมี netlify.toml หรือ package.json อยู่แล้ว ให้รวมเนื้อหา อย่าทับทั้งไฟล์

วิธีติดตั้ง (ประมาณ 20–30 นาที ครั้งเดียว)
---------------------------------------------------------------------
สำคัญ: Netlify แบบ "ลากโฟลเดอร์ไปวาง" (Drag & drop) ไม่รองรับระบบหลังบ้าน
ต้องอัปด้วย Netlify CLI (คำสั่งในเครื่อง) หรือผูกกับ GitHub แทน

1) ติดตั้งโปรแกรม (ครั้งเดียว)
   - Node.js รุ่น LTS จาก nodejs.org
   - เปิด Terminal (หรือ Terminal ใน VS Code) แล้วพิมพ์
       npm install -g netlify-cli

2) เตรียมโฟลเดอร์เว็บ
   - ใช้โฟลเดอร์เว็บชุดล่าสุด (หรือดาวน์โหลดจาก Netlify > Deploys > deploy ล่าสุด > ดาวน์โหลด)
   - แตก ZIP นี้ลงโฟลเดอร์เดียวกับ index.html
   - เปิด index.html เพิ่ม 2 บรรทัด (ต่อจากบรรทัดของธีม)
       ก่อน </head> :  <link rel="stylesheet" href="roiet-backend.css">
       ก่อน </body> :  <script src="roiet-backend.js"></script>
     (ต้องมีบรรทัดของธีม roiet-theme.css / roiet-theme.js อยู่แล้ว)

3) ตั้งรหัสลับของระบบ (RR_SECRET) — ต้องทำ ไม่งั้นเข้าสู่ระบบไม่ได้
   - สร้างรหัสสุ่ม: ใน Terminal พิมพ์
       node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
   - เข้า app.netlify.com > เลือกเว็บ roiet-route > Site configuration
     > Environment variables > Add a variable
       Key:   RR_SECRET
       Value: (วางรหัสที่ได้)
   - ห้ามเผยแพร่รหัสนี้ ถ้าเปลี่ยนรหัส ทุกคนต้องเข้าสู่ระบบใหม่

4) อัปขึ้น Netlify
   - ใน Terminal ไปที่โฟลเดอร์เว็บ (cd ชื่อโฟลเดอร์) แล้วพิมพ์ทีละบรรทัด
       npm install
       netlify login            (เปิดเบราว์เซอร์ให้กดอนุญาต)
       netlify link             (เลือกเว็บ roiet-route ที่มีอยู่)
       netlify deploy --build --prod
   - ครั้งต่อไปแก้เว็บแล้ว ใช้แค่ netlify deploy --build --prod

5) ตรวจว่าใช้ได้
   - เปิด https://roiet-route.netlify.app/api/health
     ต้องเห็น "ok":true และ "secret":true
   - เปิด https://roiet-route.netlify.app/api/fuel  ต้องเห็นราคาน้ำมัน
   - เปิดเว็บ กด "เข้าสู่ระบบ" มุมขวาบน > สมัครใช้งาน (คนแรก = ผู้ดูแลระบบ)
   - เปิด https://roiet-route.netlify.app/admin.html
   - ใน Netlify > Functions ต้องเห็น api และ fuel-cron (fuel-cron ขึ้นว่า Scheduled)

6) (ไม่บังคับ) ตั้งค่าเพิ่มใน Environment variables
   ADMIN_EMAILS        อีเมลที่ให้เป็นผู้ดูแลระบบเสมอ คั่นด้วย , เช่น a@x.com,b@y.com
   ALLOW_SIGNUP        ใส่ false = ปิดการสมัครเอง (ผู้ดูแลระบบสร้างบัญชีให้แทน)
   แจ้งเตือนเข้า Telegram:
     TG_BOT_TOKEN      สร้างบอทกับ @BotFather ใน Telegram แล้วคัดลอก token
     TG_CHAT_ID        ทักบอทหนึ่งครั้ง แล้วเปิด https://api.telegram.org/bot<TOKEN>/getUpdates
                       ดูค่า "chat":{"id": ...}
   แจ้งเตือนเข้า Discord:
     DISCORD_WEBHOOK_URL  ห้อง Discord > Edit Channel > Integrations > Webhooks > Copy URL
   แจ้งเตือนเข้า LINE (LINE Notify ปิดบริการไปแล้ว ใช้ LINE Official Account แทน):
     LINE_CHANNEL_TOKEN   Channel access token จาก LINE Developers (Messaging API)
     LINE_TO              User ID หรือ Group ID ที่จะส่งถึง
   แหล่งราคาน้ำมันสำรอง:
     FUEL_FEED_URL     ลิงก์ JSON ราคาน้ำมันที่หาเพิ่มได้ (รองรับรูปแบบ stations/ปั๊ม/ชนิด/ราคา)
     FUEL_PAGE_URL     เปลี่ยนเว็บรวมราคาทุกปั๊ม (ค่าเริ่มต้น gasprice.kapook.com)
   ตั้งค่าแล้วต้อง deploy ใหม่ 1 ครั้ง (netlify deploy --build --prod)

รายการ API (สำหรับอ้างอิงในรายงาน)
---------------------------------------------------------------------
  GET    /api/health                     ตรวจระบบ
  POST   /api/auth/register              สมัคร {email, password, name, role}
  POST   /api/auth/login                 เข้าสู่ระบบ → {token, user}
  GET    /api/auth/me                    ข้อมูลผู้ใช้ปัจจุบัน
  POST   /api/auth/password              เปลี่ยนรหัสผ่าน
  POST   /api/auth/logout-all            ออกจากระบบทุกเครื่อง
  GET    /api/sync                       ดึงข้อมูลบนคลาวด์ทั้งหมด
  PUT    /api/sync/{key}                 บันทึก (roiet.hist / roiet.fav / roiet.acc / roiet.fuel)
  POST   /api/jobs/sync                  ส่งสถานะงานจากโหมดคนขับ
  GET    /api/jobs                       รายการงาน (?state=run)
  GET    /api/jobs/{id}                  รายละเอียดงาน
  PATCH  /api/jobs/{id}                  มอบหมายคนขับ {driverEmail}
  PATCH  /api/jobs/{id}/stops/{no}       แก้สถานะจุด {st: ok|fail|todo, r}
  DELETE /api/jobs/{id}                  ยกเลิกงาน
  GET    /api/notifications              แจ้งเตือน + จำนวนที่ยังไม่อ่าน
  POST   /api/notifications/read         ทำเครื่องหมายว่าอ่านแล้ว {all:true} หรือ {ids:[]}
  GET    /api/fuel                       ราคาน้ำมันทุกปั๊ม + ปั๊มที่ถูกที่สุด (ไม่ต้องเข้าระบบ)
  GET    /api/fuel/history?days=30       ประวัติราคารายวัน
  POST   /api/fuel/refresh               ดึงราคาตอนนี้ (ผู้ดูแลระบบ)
  PUT    /api/fuel/manual                กรอกราคาเอง (ผู้ดูแลระบบ)
  GET    /api/admin/users                ผู้ใช้ทั้งหมด (ผู้ดูแลระบบ)
  POST   /api/admin/users                เพิ่มบัญชี
  PATCH  /api/admin/users/{id}           เปลี่ยนสิทธิ์ / ระงับ / รีเซ็ตรหัส
  GET    /api/admin/stats                สถิติรวม
  POST   /api/admin/notify-test          ส่งแจ้งเตือนทดสอบ
  ทุก API (ยกเว้น health, register, login, fuel) ต้องส่ง Authorization: Bearer <token>

ที่เก็บข้อมูล (Netlify Blobs): rr-users, rr-data, rr-jobs, rr-notify, rr-fuel
ดู/ลบข้อมูลได้ใน Netlify > Blobs

---------------------------------------------------------------------
เสียงธรรมชาติสำหรับหน้านำทาง (ไม่บังคับ แต่แนะนำ)
---------------------------------------------------------------------
ถ้าไม่ตั้งค่า หน้านำทางจะใช้เสียงในเครื่องแทน (ยังใช้ได้ แต่ฟังแข็งกว่า)
เลือกตั้งอย่างใดอย่างหนึ่ง (ตั้งทั้งคู่ ระบบใช้ Google ก่อน)

แบบ A — Google Chirp 3 HD (แนะนำ ฟังเหมือนคนที่สุด · ฟรี 1 ล้านตัวอักษร/เดือน)
1) เข้า console.cloud.google.com สร้างโปรเจกต์ (ต้องผูกบัญชีชำระเงิน แต่ใช้ไม่เกินโควตาฟรีไม่เสียเงิน)
2) APIs & Services > Library > ค้นหา "Cloud Text-to-Speech API" > Enable
3) APIs & Services > Credentials > Create credentials > API key
   แนะนำกด Edit API key > API restrictions > เลือกเฉพาะ Cloud Text-to-Speech API
4) Netlify > Environment variables > เพิ่ม  GOOGLE_TTS_KEY = (คีย์ที่ได้)
   (ไม่บังคับ) TTS_VOICE_F / TTS_VOICE_M ค่าเริ่มต้น th-TH-Chirp3-HD-Achernar (หญิง)
   / th-TH-Chirp3-HD-Charon (ชาย) เปลี่ยนชื่อท้ายเป็นเสียงอื่นได้ เช่น Aoede, Kore (หญิง) Puck, Orus (ชาย)
5) deploy ใหม่ แล้วเปิดหน้านำทาง > ฟันเฟือง จะขึ้น "เสียงธรรมชาติ (Google Chirp 3 HD)"

แบบ B — Azure Neural
1) สมัคร/เข้า portal.azure.com (บัญชี Microsoft ฟรี ใช้บัตรยืนยันตัวตน แต่แพ็กเกจ F0 ไม่คิดเงิน)
2) Create a resource > ค้นหา "Speech" > Create
   - Region: Southeast Asia
   - Pricing tier: Free F0 (500,000 ตัวอักษร/เดือน)
3) เปิด resource ที่สร้าง > Keys and Endpoint > คัดลอก KEY 1 และ Location/Region (เช่น southeastasia)
4) Netlify > Site configuration > Environment variables > เพิ่ม
     AZURE_SPEECH_KEY     = (KEY 1)
     AZURE_SPEECH_REGION  = southeastasia
   (ไม่บังคับ) TTS_VOICE_F / TTS_VOICE_M เปลี่ยนชื่อเสียงได้ ค่าเริ่มต้น
     th-TH-PremwadeeNeural (หญิง) / th-TH-NiwatNeural (ชาย)
5) deploy ใหม่ด้วยคำสั่งในข้อ 4 แล้วเปิดหน้านำทาง > ฟันเฟือง
   บรรทัดสถานะจะขึ้น "เสียงธรรมชาติ (Azure Neural)"
หมายเหตุ: ระบบเก็บไฟล์เสียงที่เคยพูดไว้ (rr-tts) ประโยคซ้ำไม่เรียก Azure ซ้ำ
รับเฉพาะข้อความภาษาไทยไม่เกิน 220 ตัวอักษร กันคนเอาไปใช้เป็นบริการเสียงฟรี

- ราคาน้ำมันบางปั๊มไม่ขึ้น → หน้าผู้ดูแลระบบ > ราคาน้ำมัน ดูว่าแหล่งไหน "ดึงไม่ได้"
  (เว็บต้นทางอาจเปลี่ยนรูปแบบ) กรอกราคาเองแทนได้ทันที
- fuel-cron ไม่ทำงาน → ฟังก์ชันตั้งเวลาทำงานเฉพาะเว็บที่ Published แล้ว
  ระหว่างนั้นระบบยังดึงราคาเองเมื่อมีคนเปิดเว็บและข้อมูลเก่าเกิน 2 ชม.
- หน้านำทางเสียงยังเป็นเสียงในเครื่อง → ตรวจ GOOGLE_TTS_KEY หรือ AZURE_SPEECH_KEY / REGION
  แล้ว deploy ใหม่ ทดสอบได้ที่ /api/tts/info ต้องขึ้น "provider":"google" หรือ "azure"
- ลืมรหัสผ่าน → ให้ผู้ดูแลระบบกด "รีเซ็ตรหัส" ในหน้าผู้ใช้งาน
- ผู้ดูแลระบบลืมรหัสเอง → ใส่อีเมลนั้นใน ADMIN_EMAILS ไม่ช่วยเรื่องรหัส
  ให้สมัครบัญชีใหม่ด้วยอีเมลอื่นที่อยู่ใน ADMIN_EMAILS แล้วรีเซ็ตรหัสบัญชีเดิม

ถ้าจะเลิกใช้: ลบ 2 บรรทัดใน index.html แล้ว deploy ใหม่ เว็บกลับเป็นแบบเดิม ข้อมูลในเครื่องยังอยู่ครบ
