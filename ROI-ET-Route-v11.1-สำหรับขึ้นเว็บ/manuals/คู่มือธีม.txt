ROI ET ROUTE — Premium Logistics Dashboard (ธีม v5: แผนที่สีธรรมชาติ สบายตา มีมิติ)
=====================================================================

ธีมนี้เปลี่ยนเฉพาะหน้าตาและการแสดงผลของเว็บ roiet-route.netlify.app
สิ่งที่ไม่เปลี่ยน: ระบบคำนวณ, ข้อมูลจุดส่ง, การนำเข้า Excel/CSV, ระบบแบ่งรถ,
การบันทึกประวัติ, การสำรองข้อมูล, แผนที่และการค้นหาสถานที่, ภาพสถานที่ร้อยเอ็ด
(ธีมแค่ "อ่าน" ค่าจากหน้าเว็บและข้อมูลที่เว็บบันทึกไว้ ไม่เขียนหรือแก้ข้อมูลใดๆ)

---------------------------------------------------------------------
มีอะไรใหม่
---------------------------------------------------------------------
ทั้งเว็บ
- กดเมนูแล้วเปิดเป็นหน้าแยกกัน (ไม่เลื่อนลงแล้ว) เปลี่ยนหน้าแบบนุ่มนวล
  ปุ่มย้อนกลับของเบราว์เซอร์ใช้ได้ และส่งลิงก์ตรงไปหน้าใดหน้าหนึ่งได้ เช่น
  roiet-route.netlify.app/#planner , #stats , #history , #account , #accuracy , #about
- Sidebar มีแถบแสงเรืองที่เลื่อนตามเมนูที่เลือก
- การ์ดตัวเลขนับขึ้นตอนโหลด เอียงตามเมาส์ มีแสงสะท้อน
- ปุ่มมีแสงไล่ระดับตอนชี้ และมีระลอกแสงตอนกด
- พื้นหลังลายขิด + ภาพสถานที่ร้อยเอ็ดจางๆ (ใช้ภาพเดิมของเว็บ)
- แถบหัวหน้าบอกชื่อหน้า วันที่ และสถานะบัญชี

หน้าแผนที่ (วางแผนเส้นทาง)
- เส้นทางสีส้มขอบชัด มีเงาใต้เส้นเหมือนลอยเหนือพื้นเล็กน้อย หมุดหมายเลขตกลงมาทีละจุด
- กดหมุดแล้วเห็นลำดับ เวลาถึงประมาณ เวลาเปิด-ปิดร้าน และคำเตือนสาย
- ลากสลับลำดับจุดส่งได้ (ของเดิม) และมีไฮไลต์ตำแหน่งที่จะวาง
- แถบสรุปบนแผนที่ (อัปเดตทันที): ระยะทาง เวลา จำนวนจุด แบบแถบเล็กไม่บังแผนที่
- ตอนคำนวณเส้นทางใหม่ มีป้าย "กำลังจัดเส้นทาง…" แถบโหลดด้านบน และเส้นทางสว่างขึ้น

รายหน้า
- หน้าแรก (Dashboard): การ์ดสรุป 4 ใบ, กราฟแนวโน้ม 14 วัน (ระยะทาง/ค่าใช้จ่าย/ประหยัด),
  สัดส่วนต้นทุนต่อวัน, ก่อน vs หลังจัด, ข้อมูลของฉัน + ปุ่มลัด
- สถิติ: เลือกช่วง 7 / 30 / 90 วัน / ทั้งหมด, ตัวเลขสรุป 5 ตัว, กราฟระยะทางก่อน-หลัง,
  กราฟต้นทุนเทียบเงินที่ประหยัด และการวิเคราะห์เส้นทางปัจจุบันแบบเดิม
- ประวัติ: ค้นหาชื่อร้าน/คลัง/รุ่นรถ, กรองตามช่วงเวลาและรุ่นรถ, ไฮไลต์คำที่ค้น
- บัญชี: การ์ดโปรไฟล์, สรุปข้อมูลของฉัน, เมนูตั้งค่าพื้นฐานที่กดแล้วพาไปตั้งค่าได้ทันที
- ตรวจความแม่นยำ: กราฟระบบคำนวณเทียบวิ่งจริง + วงแสดงความคลาดเคลื่อนเฉลี่ย
- เกี่ยวกับข้อมูล: การ์ดแหล่งข้อมูลและหลักการทำงาน + รายละเอียดฉบับเต็มแบบเดิม

แผนที่สีธรรมชาติ ดูสบายตา มีมิติ (ใหม่ใน v5)
- ตัดของที่ทำให้ลายตาออก: แสงเรือง วงแสงกระพริบ วงประ เมฆ และเส้นถนนที่วาดทับภาพดาวเทียม
- ภาพดาวเทียมปรับโทนให้นุ่มเป็นธรรมชาติ (ลดความจัดของสีและความคม)
- แผนที่ถนน (ตอนปิดดาวเทียม หรือโหลดภาพดาวเทียมไม่ได้) เป็นสีธรรมชาติ:
  พื้นเขียวอ่อนแบบทุ่งนา แหล่งน้ำสีฟ้า ถนนสีขาวนวล ทางหลวงสีเหลืองอ่อน
- มิติ: หมอกจางๆ ที่ขอบฟ้า ระยะไกลเบลอเล็กน้อย หมุดตั้งบนพื้นพร้อมเงา และเงาใต้เส้นทาง
- ป้ายชื่ออำเภอหลบกันเอง ไม่บังหมุด และจางลงเมื่ออยู่ไกล
- ป้ายเวลาถึงซ่อนไว้ก่อน ชี้ที่หมุดเพื่อดูทีละจุด หรือกดปุ่ม "เวลาถึง" ที่หัวแผนที่เพื่อแสดงทุกจุด
  (ป้ายคลังสินค้าแสดงเวลาออก-กลับไว้ตลอด)
- มุมเอียงประมาณ 46 องศาเหมือนเดิม เปิดหน้าแผนที่แล้วจัดมุมและซูมให้เห็นทั้งเส้นทางพอดีหน้าต่างเอง
- ปุ่ม "ดาวเทียม" "มุมมอง 3D" และ "เวลาถึง" ที่หัวแผนที่ เปิด/ปิดได้ เว็บจำค่าที่เลือกไว้
- คลิกบนแผนที่เพื่อเลือกพิกัดยังได้ตำแหน่งตรงเหมือนเดิม แม้อยู่ในมุมเอียง
- ถ้าโหลดภาพดาวเทียมไม่ได้ (ไม่มีอินเทอร์เน็ต) จะใช้แผนที่ถนนสีธรรมชาติให้เอง
- จุดส่งที่เพิ่มเอง (ชื่อ + พิกัด) กด × ลบออกแล้ว ชื่อบนแผนที่และในรายการคลังจะหายไปด้วย
  (เดิมลบออกจากรายการแล้ว แต่ชื่อยังค้างบนแผนที่ ทำให้ดูเหมือนลบไม่ได้)
- หมุดฟ้า "+" ที่ขึ้นตอนแตะแผนที่เลือกพิกัด: กด × ที่ป้ายแล้วหมุดจะหายไปด้วย (เดิมปิดแค่ป้าย หมุดยังปักค้าง)
- บนมือถือ ป้ายข้อมูลบนแผนที่จะอยู่ในกรอบเสมอ กดปุ่ม × ได้

หมายเหตุเรื่องภาพดาวเทียม
- ใช้ภาพจาก Esri World Imagery และแสดงเครดิตไว้ที่มุมขวาล่างของแผนที่แล้ว
  การใช้งานอยู่ภายใต้เงื่อนไขการใช้งานของ Esri ถ้าจะนำเว็บไปใช้เชิงพาณิชย์
  ควรตรวจเงื่อนไขก่อน หรือเปลี่ยนไปใช้บริการแบบมีคีย์
- เปลี่ยนแหล่งภาพได้ที่บรรทัด satUrl ใน roiet-theme.js
- หมุดตั้งตรงแบบ 3 มิติทำงานบน Chrome, Edge, Android
  ส่วน Safari/Firefox ใช้วิธียืดหมุดและป้ายตามตำแหน่งให้ดูตั้งตรงแทน (ทุกอย่างใช้งานได้เหมือนกัน)

ไฟล์ในชุดนี้
- roiet-theme.css  : หน้าตา สี แอนิเมชัน และการจัดวาง
- roiet-theme.js   : การแยกหน้า กราฟ ลูกเล่นแผนที่ และตัวเลขสรุป

วิธีติดตั้ง (ใช้เวลาประมาณ 5 นาที)
---------------------------------------------------------------------
1) เอาไฟล์เว็บชุดล่าสุดมาไว้ในเครื่อง
   - ถ้ามีโฟลเดอร์เว็บอยู่ในคอมอีกเครื่อง ใช้โฟลเดอร์นั้นได้เลย
   - หรือดาวน์โหลดจาก Netlify: เข้า app.netlify.com > เลือกเว็บ roiet-route
     > Deploys > กดรายการ deploy ล่าสุดที่ขึ้น Published
     > กดปุ่มดาวน์โหลด (ลูกศรลง) จะได้ไฟล์ ZIP ของเว็บทั้งชุด แล้วแตกไฟล์

2) คัดลอก roiet-theme.css และ roiet-theme.js ไปไว้ในโฟลเดอร์เดียวกับ index.html
   (ถ้าเคยใส่ธีมรุ่นก่อนไว้แล้ว ให้ทับไฟล์เดิมได้เลย ไม่ต้องแก้ index.html ซ้ำ)

3) เปิด index.html ด้วย VS Code (หรือ Notepad) แล้วเพิ่ม 2 บรรทัด

   ก) วางบรรทัดนี้ไว้ก่อน </head>
      <link rel="stylesheet" href="roiet-theme.css">

   ข) วางบรรทัดนี้ไว้ก่อน </body> (บรรทัดท้ายๆ ของไฟล์)
      <script src="roiet-theme.js"></script>

   บันทึกไฟล์ (Ctrl+S)

4) ทดสอบในเครื่อง: เปิด index.html ด้วย Chrome หรือใช้ Live Server ใน VS Code
   ควรเห็นเมนูซ้ายสีกรมท่า และกดแต่ละเมนูแล้วเปลี่ยนเป็นหน้าใหม่

5) อัปขึ้น Netlify
   - ถ้าเคยลากโฟลเดอร์ขึ้นเอง: เข้าเว็บ roiet-route ใน Netlify > Deploys
     แล้วลากโฟลเดอร์เว็บทั้งโฟลเดอร์ไปวางในช่องอัปโหลด
   - ถ้าเว็บผูกกับ GitHub: commit แล้ว push ตามปกติ Netlify จะ deploy ให้เอง

---------------------------------------------------------------------
ถ้าอยากกลับไปใช้หน้าตาเดิม
---------------------------------------------------------------------
- ลบ 2 บรรทัดที่เพิ่มในข้อ 3 แล้ว deploy ใหม่
- หรือใน Netlify > Deploys เลือก deploy ก่อนหน้า แล้วกด Publish deploy

หมายเหตุ
- กราฟในหน้าแรก สถิติ และความแม่นยำ ใช้ข้อมูลจากประวัติและผลทดสอบที่บันทึกไว้
  ถ้ายังไม่เคยบันทึก จะขึ้นกล่องแนะนำวิธีใช้แทนกราฟ
- ถ้าเปิดแบบลดการเคลื่อนไหว (Reduce motion) ในเครื่อง แอนิเมชันจะปิดเองอัตโนมัติ
- ถ้าวันหลังแก้โค้ดเว็บจนชื่อ id สำคัญเปลี่ยน ส่วนเสริมของธีมจะข้ามไปเอง เว็บไม่พัง
- ทดสอบแล้วที่จอ 1920/1440 แท็บเล็ต 1024 และมือถือ 390 พิกเซล โดยกดปุ่มเดิมทุกตัว
  เทียบกับเว็บเดิม: แท็บแผนที่ ล้าง/ใส่จุดตัวอย่าง นำเข้ารายชื่อ บันทึกประวัติ
  เปิดเส้นทางจากประวัติ โหมดคนขับ และพิมพ์ใบงาน ผลการทำงานเหมือนเดิมทุกข้อ
